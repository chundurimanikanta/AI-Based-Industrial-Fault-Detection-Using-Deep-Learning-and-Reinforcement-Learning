# AI-Based-Industrial-Fault-Detection-Using-Deep-Learning-and-Reinforcement-Learning
AI-Based Industrial Fault Detection using Deep Learning and Reinforcement Learning. A comparative study of seven models, including ResNet50, MobileNetV2, Custom CNN, CNN-LSTM, CNN-GRU, DQN, and Actor-Critic, for automated good vs. defective product classification using the MVTec dataset.
